# Contributing to CLA — Cameroonian Language AI

Thank you for considering a contribution to CLA. The project is at an early, foundation-building stage (see [Project Status](README.md#-project-status)), which means there is real room to shape it — but also that processes below are intentionally lightweight and will evolve.

You do **not** need to be an AI researcher to contribute. See the [Contributing section of the README](README.md#-contributing) for the kinds of contributors CLA is looking for.

---

## Ways to contribute right now

CLA's current phase is **Phase 0 — Research & Community** (see [Roadmap](README.md#-roadmap)). The most valuable contributions today are:

- **Language expertise** — corrections, sources, or first-hand knowledge about any language discussed in [`docs/language-landscape.md`](docs/language-landscape.md), especially speaker estimates, existing dictionaries/corpora, and orthography status. Numbers in that document are estimates from public sources and are expected to be wrong in places.
- **Pointers to existing resources** — datasets, dictionaries, academic papers, ASR/MT models, or ongoing projects for any Cameroonian language, even ones not yet listed.
- **Community connections** — introductions to native-speaker communities, linguists, universities, missions/translation organizations, or diaspora associations for Fulfulde, Ewondo, or Ghomala' (Bandjoun) — CLA's first three languages.
- **Engineering** — early tooling such as data schemas, validation scripts, or a lightweight collection app (see the `CLA Collect` concept in the README).
- **Review** — reading drafts of documents like the language landscape or future dataset/consent policies before they're finalized.

## How to propose a change

1. **Open an issue first** for anything non-trivial (a new language candidate, a dataset schema, a policy change). This keeps discussion visible and avoids wasted work — especially important for decisions with cultural or community sensitivity.
2. **Small fixes** (typos, broken links, obvious corrections) can go straight to a pull request.
3. Reference the related issue in your PR description.

## Data and language contributions

CLA has not yet opened data collection (text, audio, or translations). Before any voice or text data is collected from contributors, CLA will publish a **consent, licensing, and retention policy** (tracked in the roadmap). Please do not submit personal recordings or third-party copyrighted text as part of a contribution until that policy exists — open an issue instead to discuss what you'd like to contribute.

## Code style and PRs

- Keep pull requests focused on one change.
- Explain *why* in the PR description, not just *what*.
- Be respectful of the fact that reviewers may not be native speakers of every language discussed — flag anything that needs a native-speaker check.

## Code of conduct

Be respectful, especially when discussing languages, communities, and cultural knowledge that are not your own. Cameroonian languages represent real communities, histories, and identities — treat contributions about them with the same care you'd want for your own.

## Questions

Open an issue with the `question` label, or start a discussion thread if the repository has GitHub Discussions enabled.
